# Black-box Skill scenarios

`scenarios.json` defines fresh-session Harness cases. Runner puts `stub-horizon` on `PATH` as `horizon`, points `HORIZON_STUB_STATE` at case `stub` JSON, captures `HORIZON_STUB_LOG`, invokes `horizon` Skill with case prompt, and grades observable questions, guidance, stop points, and command trace against `expect`.

`missing-cli` omits stub from `PATH`. Multi-turn cases return listed `userReplies` in order. No scenario supplies credentials to Agent context. `python3 tests/verify.py` validates suite and stub responses without model calls.

Automation cases pair the six journey concepts with present and absent process support. The restricted and failed variants additionally grade authority handoffs and truthful execution reporting. Their `trace` grades selected connection, read-only scope, Discovery bootstrap and following returned links; `expect` grades questions, selected contexts, evidence and stop points. These proposal/inspection cases stop before approval: actual mutations, responses, recovery and Real/Test isolation are proved by Core's Installation integration journeys.

Run `tests/run-automation.py` with `--contracts` pointing to temporary current HTTP captures and `--output` pointing outside this repository. Core's optional `TestProcessGuidanceFixtureCapture` produces the supported, restricted, failed and absent fixtures when `AUTOMATION_FIXTURE_DIR` names an external directory. Use the Core checks and guarded quarterly benchmark to verify effects before capturing. The runner uses fresh ephemeral Codex sessions and stores answers, CLI traces, harness events and structural checks locally. Review each answer and trace against its `expect` rubric; structural checks alone do not prove behavioral compliance. `--case` selects scenarios to rerun; `--grade-only` rechecks saved traces against the current captures without model calls.

The stub consumes runtime responses only from the externally supplied `HORIZON_STUB_CONTRACT` file. It refuses missing requests and requests that do not follow a previously returned link, preserving the selected connection. Keep all Installation responses, credentials and model transcripts outside this repository: scenario policy never enumerates process routes, schemas, payloads or supported catalog values. Existing static bootstrap cases remain unchanged.
